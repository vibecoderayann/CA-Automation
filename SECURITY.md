# Security Policy

## 🔒 100% Offline-First Architecture

**CA Copilot** is designed with a strict zero-telemetry, offline-first security model. Financial data, PAN/GST records, ledger extracts, and client working papers are processed strictly within the local process memory on your machine and never transmitted to external cloud servers.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within CA Copilot:

1. **Do not create a public GitHub issue.**
2. Send an email to `ayankhanmaster@gmail.com` with:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Impact assessment
3. You will receive an initial response acknowledging your report within 48 hours.
4. Once verified, a patch will be prepared and published in a security advisory release.

Thank you for helping keep financial and audit automation secure and confidential!
